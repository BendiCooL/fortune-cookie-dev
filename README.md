Entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/c/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
competition on [make.fun](https://make.fun).

The entry is one original line of fortune-cookie wisdom for a software
developer — a TODO as a letter to the stranger who will inherit it, who
shares your name:

> Every TODO you write is a letter to a stranger who shares your name.

`main.ts` (Node 22, stdlib only, deterministic, no network) writes that
line — 68 Unicode code points, no trailing newline — to
`/output/entry.txt`, after checking it against the competition gate (1 to 120
characters, not only white space).

Run it with:

```sh
node main.ts
```
